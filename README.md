# Site Fonte

## Onde mexer

- `interfaceinicial.html`: página inicial.
- `masculino.html`, `feminino.html` e `lancamentos.html`: catálogos.
- `Css/global.css`: cabeçalho, cores, fontes, botões e rodapé.
- `Css/inicio.css`: carrossel, marcas e avaliações.
- `Css/catalogo.css`: cards e listas de produtos.
- `Css/produto.css`: detalhes dos tênis.
- `Css/formularios.css`: formulários.
- `Css/carrinho.css`: carrinho e pagamento.
- `Css/paginas/`: ajustes de páginas específicas, incluindo ADM.
- `Js/`: funções em JavaScript.
- `Css/legado/`: arquivos antigos para consulta; não são usados nas páginas.

## Como testar

Abra `interfaceinicial.html` pelo XAMPP. Antes de substituir arquivos, guarde uma cópia do site atual.

O `conexao.php` não está incluído. Mantenha o arquivo local do banco de dados.
